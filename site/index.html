Features

Everything you need to stay on top of your site, in one lightweight plugin.

Event tracking

16 built-in event types across posts, users, comments, plugins, themes, and WordPress core — singular or aggregated.

PHP error tracking

Aggregates warnings, notices, and deprecations so you spot trouble before your visitors do.

Weekly digest

Active → frozen → emailed lifecycle. Reports freeze Sunday 23:55 and ship to your inbox Monday 00:05.

AI summaries

Optional natural-language summaries using WordPress 7's native AI API. Bring your own provider, your own keys.

Smart recommendations

Extensible filter API

Track custom events from any plugin with sybgo_track_event(). Filter hooks for every step of the pipeline.

Frequently asked questions

Is Sybgo really free?

Yes. Sybgo is free and open-source under GPL-2.0-or-later. No paid tier, no upsells, no telemetry.

What data does Sybgo collect?

Sybgo records site events (posts published, users registered, plugin updates, PHP errors, etc.) in your own WordPress database. No personally identifying information beyond what already exists in WordPress is collected.

Does Sybgo send data to external services?

Not unless you opt in. AI summaries are optional and require you to configure your own provider via the WordPress AI API. Without it, Sybgo runs entirely on your server.

Does Sybgo work without WordPress 7?

Yes. Event tracking and weekly digests work on WordPress 5.0+. Only the AI summary feature requires the native AI API introduced in WordPress 7.

Can I extend Sybgo from my own plugin?

Yes. Call sybgo_track_event() to record custom events, and use the documented filters to customize tracking, report generation, and digest rendering. See the Extension API docs.

Where do I report bugs or request features?

Open an issue on the GitHub repository. Pull requests are welcome.
