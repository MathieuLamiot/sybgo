Sybgo User Guide

Sybgo — “Since You’ve Been Gone” — is a WordPress plugin that watches your site for meaningful activity (new posts, user signups, plugin updates, comments, PHP errors) and emails you a weekly digest so you always know what changed while you were away. Everything stays on your site: events are stored in your own WordPress database, and emails are sent through standard wp_mail().

Quick start

  1. Install and activate Sybgo. See Installation.
  2. Add your email under Settings → Sybgo → Email Recipients. See Settings.
  3. Wait for Monday — your first digest arrives automatically. Or open the WordPress dashboard and click “Preview This Week’s Digest” on the Site Activity Digest widget to see what would be sent right now.
