Tracks meaningful WordPress events and sends weekly email digests.

== Description ==

Since You've Been Gone — stay informed about what's happening on your site.
Sybgo tracks meaningful events (posts, users, updates, comments) and sends a weekly digest email to configured recipients every week.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/sybgo` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Navigate to Settings > Sybgo to configure email recipients and options.
